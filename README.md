# LangChain-LLM-Applications
Practical implementations of LLM applications using LangChain, Prompt Engineering and Language Models

## 📌 Project Overview
This repository contains practical learning exercises and implementations of Large Language Model (LLM) applications using LangChain.

The objective is to understand how LangChain simplifies the development of AI-powered applications by connecting language models, prompts, document loaders and other components.

## 🎯 Learning Objectives
- Understand LangChain architecture and fundamentals.
- Work with Large Language Models (LLMs).
- Learn Prompt Engineering and Prompt Templates.
- Integrate OpenAI and Hugging Face models.
- Understand document loading and processing.
- Build basic LLM-powered applications.
- Explore Retrieval-Augmented Generation (RAG).

## ⚙️ Installation

Install the required Python packages:

```bash
pip install langchain
pip install langchain-openai
pip install langchain-huggingface
pip install jupyter
```

Additional packages may be required depending on the notebook.

## 🔑 API Configuration

For OpenAI-based applications, configure your API key securely using environment variables.

Never upload API keys or passwords to GitHub.

## ▶️ How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Configure API keys if required.
4. Open the notebooks using Jupyter Notebook or Google Colab.
5. Execute the notebook cells sequentially.
